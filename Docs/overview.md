w# 🎮 GodotGame プロジェクト概要

> **🎯 プロジェクト**: GodotGame - MVVM/Rxアーキテクチャを採用したアクションRPG

## 📋 プロジェクト概要

GodotGameは、Godot 4エンジンを使用したアクションRPGゲームです。MVVM（Model-View-ViewModel）パターンとリアクティブプログラミング（Rx）を組み合わせた独自のアーキテクチャを採用し、保守性と拡張性を重視した設計となっています。

## 🎯 プロジェクト目標

### 🎮 ゲームプレイ
- **ジャンル**: アクションRPG
- **プラットフォーム**: PC（Windows/Linux/macOS）
- **ターゲット**: 中級〜上級ゲーマー
- **プレイ時間**: 20-40時間

### 🏗️ 技術目標
- **アーキテクチャ**: MVVM/Rxパターンの実装
- **パフォーマンス**: 60FPS安定動作
- **保守性**: モジュラー設計による拡張性
- **テスト**: 自動テストによる品質保証

## 🧱 技術スタック

### 🎮 ゲームエンジン
- **Godot 4**: メインゲームエンジン
- **C#**: メインプログラミング言語
- **GDScript**: スクリプティング言語

### 🏗️ アーキテクチャ
- **MVVM**: Model-View-ViewModelパターン
- **Reactive Programming**: リアクティブプログラミング
- **Event-Driven**: イベント駆動設計
- **Component-Based**: コンポーネントベース設計

### 🧪 テスト・品質
- **GUT**: Godot Unit Test
- **NUnit**: C#単体テスト
- **CI/CD**: GitHub Actions
