# 共通開発ワークフロー

プルリクエスト作成や Issue 編集、テスト実行など、複数のドキュメントで共通して利用する作業手順をまとめています。詳細な各手順はリンク先のドキュメントを参照してください。

## 主な項目

- **テスト実行**: [[GodotTestCommand.md|Godotテスト実行コマンド]] に記載のコマンドで実施します。
- **プルリクエスト作成**: [[PullRequestProcedure.md|プルリクエスト手順]] を確認してください。
- **Issue 編集**: [[GithubIssueEditingWorkflow.md|GitHub Issue編集ワークフロー]] を参照します。
- **テストフロー**: 自動化されたテストの流れは [[AI_Agent_TestWorkflow.md]] にまとめています。

これらの共通ワークフローを把握することで、ドキュメント間の重複を避け、一貫した開発プロセスを保てます。
